# SPECS Index

This folder contains UI specification packs grouped by app flow.

## Structure

- `ADMIN/` - Admin and layout management flow specs.
- `CLIENT/` - Grocery shopping and navigation flow specs.
- `LANDING/` - Marketing and onboarding flow specs.

## Reading order for agents

1. Open the flow folder that matches the task.
2. Read the `*-specs.md` file first.
3. Inspect the referenced PNGs in the same folder for visual context.

## Spec format

Each spec file follows this structure:

- Purpose
- Referenced screens
- User happy path
- UI behaviors
- Interaction details
- Important notes
