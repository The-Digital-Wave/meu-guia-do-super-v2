## User Happy Path

1. The user opens the landing page.
2. The user reviews the app message and main call to action.
3. The user scans partner logos and the app flow explanation.
4. The user watches the demo video section.
5. The user reads testimonials and contact information.
6. The user opens the login or sign up modal from the avatar area (login-1.png).

## UI Behaviors

- Header contains logo, navigation, and avatar access (landing-0.png).
- Hero section presents the app motto ("O seu assistente de compras inteligente. Menos tempo entre prateleiras. Mais qualidade de vida.") and a "Assistir demo" button anchor button (place image ../src/assets/hero.png).
- Partner logos slide horizontally in a carousel (landing-2.png).
- Step-by-step section: steps alternate left and right, each step with text on one side and an app screenshot image on the other (landing-3.png). Use images available at ../src/assets/etapa-\*.png.
- Video demo (landing-4.png), testimonials (landing-5.png), contact form and footer (landing-6.png for reference, place image ../src/assets/contact-form.png beside the contact form) are separate sections.

## Interaction Details

- The login or sign up modal opens from the avatar interaction.
- The demo button anchors to the video section.
- Navigation remains visible as the user scans the page.
